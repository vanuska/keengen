📖Как пользоваться

keengen кормит XKeen-UI файлами 01–06. Полный текст — в README репозитория.

  1. Вставьте share-ссылки vless:// / hy2:// (не https:// подписку).
  2. Нажмите «Прочитать ссылки». Radio слева — какой тег пойдёт в 05_routing.json.
  3. «Скачать все файлы разом» → ZIP. В XKeen-UI положите JSON в /opt/etc/xray/configs/ и restart.
  4. Читать и заливать на роутер по SSH можно только если открыт локальный helper: python keengen.py → http://127.0.0.1:8765/.
