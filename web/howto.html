📖Как пользоваться

Два режима: keengen на ПК и keengen на Keenetic. Полный текст — в README репозитория.

местное время
🏠 На главную
  1. Вставьте share-ссылки vless:// / hy2:// (не https:// подписку).
  2. «Прочитать ссылки». Radio слева — какой тег пойдёт в 05_routing.json.
  3. «Скачать все файлы разом» → ZIP в /opt/etc/xray/configs/ и restart XKeen — либо «Залить» с ПК / с Keenetic.
  4. keengen на ПК: start.bat / python3 start.py → http://127.0.0.1:8765/ — SSH, бэкапы, установка и снятие IPK.
  5. keengen на Keenetic: IPK с GitHub Releases → http://<router>:1001/ рядом с XKeen-UI на :1000. Откат IPK / «Удалить IPK» — только с ПК.
  6. Обновления: при открытии и обновлении страницы (F5) keengen проверяет latest на GitHub и показывает строку версий / кнопку «Обновить IPK…». Автоматически пакет не ставится — нужен клик по кнопке.

Вход: пароль или SSH-ключ

К роутеру по SSH — логин + пароль или логин + SSH-ключ. Это Entware SSH (Dropbear), не пароль веб-UI KeeneticOS.

  1. Обычный путь: в «Настройка входа» — логин (часто root), пароль Entware, порт (часто 22) → «Сохранить». Переменную KEENGEN_SSH_KEY заводить не нужно.
  2. Ключ: если не хотите пароль в форме или на роутере уже вход по ключу — пароль в форме пустой, на ПК env KEENGEN_SSH_KEY = полный путь к приватному ключу.
  3. Windows: ssh-keygen -t ed25519 -f %USERPROFILE%\.ssh\keengen_ed25519 → содержимое *.pub в authorized_keys на роутере (типичный Entware Dropbear: /opt/etc/dropbear/authorized_keys; OpenSSH: ~/.ssh/authorized_keys) → set KEENGEN_SSH_KEY=%USERPROFILE%\.ssh\keengen_ed25519 до запуска start.py.
  4. Пустой пароль без KEENGEN_SSH_KEY = ошибка входа.

Подробнее в репозитории: docs/howto.md (раздел «Вход: пароль или SSH-ключ»).

  1. Paste share links vless:// / hy2:// (not an https:// subscription).
  2. “Read links”. The radio on the left picks which tag goes into 05_routing.json.
  3. “Download all files” → ZIP into /opt/etc/xray/configs/ and restart XKeen — or “Write” from PC / Keenetic.
  4. keengen on PC: start.bat / python3 start.py → http://127.0.0.1:8765/ — SSH, backups, install and remove IPK.
  5. keengen on Keenetic: IPK from GitHub Releases → http://<router>:1001/ next to XKeen-UI on :1000. IPK rollback / “Remove IPK” — PC only.
  6. Updates: on open and page refresh (F5) keengen checks GitHub latest and shows the version line / “Update IPK…” button. It does not auto-install — you must click the button.

Login: password or SSH key

SSH to the router uses login + password or login + SSH key. That is Entware SSH (Dropbear), not the KeeneticOS web UI password.

  1. Usual path: in “Login settings” — login (often root), Entware password, port (often 22) → “Save”. You do not need KEENGEN_SSH_KEY.
  2. Key: if you prefer no password in the form, or the router already uses key login — leave the password empty, and on the PC set env KEENGEN_SSH_KEY to the full path of the private key.
  3. Windows: ssh-keygen -t ed25519 -f %USERPROFILE%\.ssh\keengen_ed25519 → put *.pub into authorized_keys on the router (typical Entware Dropbear: /opt/etc/dropbear/authorized_keys; OpenSSH: ~/.ssh/authorized_keys) → set KEENGEN_SSH_KEY=%USERPROFILE%\.ssh\keengen_ed25519 before start.py.
  4. Empty password without KEENGEN_SSH_KEY = login error.

More in the repo: docs/howto.md (section “Login: password or SSH key”).
