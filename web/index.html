Установить keengen на Keenetic (Entware)

Нужен SSH под root (в «Настройка входа»), если keengen на ПК. Кнопка берёт latest с GitHub, делает бэкап, ставит/обновляет IPK и UI keengen на Keenetic (:1001). XKeen-UI на :1000 не трогается.

    Вход на Keenetic
    
      
    Название, адрес, порт, логин и пароль Entware SSH. «Сохранить» проверяет вход по SSH и запоминает подключение в этом браузере. Пока вход не сохранён, «Прочитать с Keenetic» выключена. Пароль не в git и не в логи. С интернета нельзя — только из дома.
